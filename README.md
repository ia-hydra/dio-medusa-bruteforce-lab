# Scripts e execução segura

Os testes deste projeto são executados manualmente no Kali, com escopo confirmado e rede isolada. Não há automação de ataque incluída para evitar execução acidental fora do laboratório.

Antes de qualquer teste:

1. confirme que o IP pertence à VM vulnerável;
2. valide a janela de teste e a autorização;
3. use listas mínimas e baixa concorrência;
4. registre evidências sem credenciais reais;
5. interrompa ao atingir o objetivo.
